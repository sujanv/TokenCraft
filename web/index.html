Algorithm Comparison Deep Dive

How each tokenizer approaches the problem

1. Byte-Pair Encoding (BPE)

Training: Starts with 256 byte tokens. Counts adjacent pair frequencies across pre-tokenized chunks, greedily merging the most frequent pair in each step.

Used in: GPT-2, GPT-3, GPT-4, LLaMA, RoBERTa.

Advantage: Eliminates out-of-vocabulary tokens while compressing repetitive sequences efficiently.

2. WordPiece

Training: Instead of raw frequency, evaluates candidate pair merges by Likelihood Ratio: Score = count(u, v) / (count(u) * count(v)).

Used in: BERT, DistilBERT, Electra.

Advantage: Prioritizes subwords that carry high mutual information rather than purely common characters.

3. Character & Baseline Models

Character-Level: Vocabulary size remains tiny (100–300), but token sequences become 4-6x longer, increasing transformer attention computation quadratic cost.

Word-Level: Sequences are short, but vocabulary explodes into tens of thousands of words, unable to handle typos or morphological suffixes.
